# SABR Accessories

Premium Textile & Garment Accessories Supplier Website

## Overview
Single-page HTML website for SABR Accessories, a Dhaka-based textile and garment accessories supplier.

## Features
- Modern UI with glassmorphism design
- 14 product categories with MOQ, lead times, and color swatches
- Interactive product modals
- WhatsApp quote form integration
- Responsive design (mobile-friendly)
- Animated backgrounds and scroll animations

## Deploy to cPanel
1. Download ZIP from GitHub
2. Upload to cPanel → File Manager → public_html
3. Extract all files
4. Done! Visit your domain

## Tech Stack
- Single HTML file (no build tools)
- Font Awesome 6 icons
- Google Fonts (Space Grotesk, Playfair Display, Inter)
- AOS.js scroll animations
- CSS Glassmorphism + 3D effects
